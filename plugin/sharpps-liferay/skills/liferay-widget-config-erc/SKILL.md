# Liferay widget configuration by ERC

Use when a preference, page-definition widget config or shared URL references
another Liferay entity. This general rule is portable; the migration statuses
and numeric examples in references belong to an earlier `modules/search` workspace.

## Workflow

1. Inventory entity references in preferences, nested JSON, picker payloads,
   indexed field names and externally visible URL tokens.
2. Persist an explicit, reused `externalReferenceCode`, not a numeric primary
   key. Resolve the ERC to the current instance's ID at the point of use.
3. Include entity type and group/site scope in resolution and cache keys;
   request-scoped caching avoids repeated lookups without stale cross-request IDs.
4. If the stock picker returns an ID, convert ID → ERC once when saving.
   Keep transient inputs outside automatic preference persistence conventions.
5. Pass resolved IDs to query/index-name builders; keep data-carrier POJOs free
   of services. Do not write the resolved ID back into configuration.
6. Audit breadcrumb and row navigation tokens as well as preferences; migrate
   public folder tokens to ERC while keeping internal parent walks numeric.
7. Check import/recreation behavior and unresolved ERC handling explicitly.
   The cited folder implementation falls back to no filter; decide whether
   that broadening is appropriate for the current requirement.

## Critical constraints

- Explicit ERC reuse is required; autogenerated/different ERCs do not magically
  make content portable across initializer, batch, staging or LAR operations.
- `definitionId` identifies a DDMStructure; `subTypeId` identifies a
  DLFileEntryType. They are different ID spaces, not interchangeable values.
- The earlier workspace fixed `definitionERC` and `rootFolderERC`, but
  **subTypeId remains a separate TODO**. Do not claim content-import work fixed it.
- Folder resolution dispatches DLFolder/JournalFolder/KBFolder differently;
  KB uses `getKbFolderId()`. Preserve literal `"0"` as the root sentinel, not an ERC.
- Stock ADT `displayStyleGroupId` can be paired with group key/ERC fallback.
  Inspect actual lookup code before blindly migrating that established core pattern.
- Numeric IDs in DDM indexed field names silently break facets after recreation;
  resolving an ID only once at configuration save time is not portable.
